# Trademark and Brand Usage

**[English](TRADEMARK.md) · [简体中文](docs/zh-CN/TRADEMARK.md)**

The Apache-2.0 license grants copyright and patent rights. It does **not** grant
trademark rights.

## Names and marks

The following names and marks are used to identify the project and its
maintainers:

- **Rolling-Memory**
- **Rocareer**
- **Rolling**
- **PsychologyLake.org.cn**

No logo files are currently distributed as trademarks.

## Permitted use

You may use the project name to:

- refer truthfully to the project, its documentation, or its source code;
- describe an unmodified distribution of the project;
- link to the official repository or documentation.

When you do so, do not suggest that your product, service, or fork is endorsed
by the project maintainers unless you have written permission.

## Not permitted without written permission

- Using the names or marks in a product name, company name, domain name, app
  store listing, or social account in a way that is likely to confuse users
  about the source of the product.
- Using the names or marks to imply sponsorship, certification, or official
  status.
- Registering confusingly similar trademarks or domain names.

## Forks and modified versions

Forks and modified versions are welcome under the Apache-2.0 license. If you
distribute a modified version, state clearly that it is modified and is not the
official project. Do not use the official names as the primary brand of your
fork.

## Questions

For trademark or brand questions, contact
[support@psychologylake.org.cn](mailto:support@psychologylake.org.cn).
