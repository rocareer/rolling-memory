# 商标与品牌使用

**[English](../../TRADEMARK.md) · [简体中文](TRADEMARK.md)**

Apache-2.0 许可授予版权与专利权，但**不**授予商标权。

## 名称与标识

以下名称与标识用于指代本项目及其维护者：

- **Rolling Memory**
- **Rocareer**
- **Rolling**
- **PsychologyLake.org.cn**

目前没有任何徽标文件作为商标分发。

## 允许的使用

你可以使用项目名称以：

- 如实指代本项目、其文档或源代码；
- 描述本项目的未修改分发版本；
- 链接到官方仓库或文档。

使用时，除非获得书面许可，不得暗示你的产品、服务或分支获得项目维护者的背书。

## 未经书面许可不得使用

- 在产品名、公司名、域名、应用商店条目或社交账号中使用上述名称或标识，且可能使用户对产品来源产生混淆。
- 使用上述名称或标识暗示赞助、认证或官方身份。
- 注册易混淆的商标或域名。

## 分支与修改版本

Apache-2.0 许可欢迎分支与修改版本。分发修改版本时，请明确说明其已被修改且并非官方项目；
不得将官方名称作为分支的主要品牌。

## 问题

商标或品牌相关问题请联系 [support@psychologylake.org.cn](mailto:support@psychologylake.org.cn)。
