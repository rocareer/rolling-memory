# Examples

**[English](README.md) · [简体中文](README.zh-CN.md)**

These files are copyable wiring samples, not runtime dependencies.

**Preferred one-command setup** (writes each harness's skill and MCP registration with backup,
idempotency and conflict protection; matrix and criteria in [docs/harness.md](../docs/harness.md)):

```bash
rolling-memory install --list        # list harness targets and detection results
rolling-memory install --dry-run     # preview planned changes
rolling-memory install --with-hooks  # install (skill + MCP + UserPromptSubmit hook)
rolling-memory install --check       # verify: static registration + live MCP handshake
```

The launchers generated by `install` bake in the absolute binary path (POSIX
`rolling-memory.sh` / Windows `rolling-memory.cmd`), so install the binary first via `bash install.sh`
(or build `bin/rolling-memory` from source).

The samples below are **manual equivalents** — copy them when wiring by hand, or when connecting a
harness that is not in the built-in registry.

## MCP & Hook Configuration Samples

- [mcp-config.json](mcp-config.json) — generic stdio MCP configuration (replace `command` with the
  absolute binary path or the launcher generated by `install`).
- [zcode-plugin/](zcode-plugin/) — ZCode plugin shell: `mcpServers.rolling-memory` plus `UserPromptSubmit` hook.
- [claude-code/settings.json](claude-code/settings.json) — Claude Code MCP + `UserPromptSubmit` hook configuration.
- [dsh-plugin/package.json](dsh-plugin/package.json) — DeepSeek Harness (`dsh`) plugin bundle manifest.

Before manual wiring, initialize the local configuration and SQLite vault:

```bash
rolling-memory init --write-config
rolling-memory status
```

ZCode plugin: copy `zcode-plugin/` into your plugin directory (or register it as a local marketplace
entry); after enabling it, confirm the `rolling-memory` MCP server appears and the
`UserPromptSubmit` hook fires. `db` and `scope` inside the plugin are user config — change them in
the plugin settings after installation.

## Local Sync, Diagnostics & Web Console

```bash
rolling-memory sync status           # inspect L1/L2/L3 local vault and harness dialogue sync status
rolling-memory sync reconcile        # import recent harness dialogues and refresh mounted L1 folders
rolling-memory doctor --json         # verify local mode, permissions, and database health
rolling-memory panel                 # open the local web console (http://localhost:8008/#/admin)
```
